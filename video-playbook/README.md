## 1. ภาพรวมรูปแบบคลิป
- **แนวตั้ง 9:16** 1080×1920, 30fps, ยาว **~95–100 วินาที**
- ไม่มีคนออกกล้อง ใช้ **กราฟ TradingView จริง (OANDA:XAUUSD)** + ข้อความกราฟิก + เสียงพากย์
- เปลี่ยนภาพ/ข้อความ **ทุก 2–4 วินาที** ตามประโยคพากย์ (คลิปเดียวมี ~30 ช็อต)
- พากย์เร็ว ประโยคสั้น ลงท้าย "ครับ" บ่อย ๆ → ภาษาลาวใช้ "ເດີ" (หรือ "ຄັບ")
- ผู้พากย์เรียกตัวเองด้วย **ชื่อช่อง** ("Better ยังมองฝั่งขาย") → ให้ใส่ชื่อช่องของคุณแทน
- เพลงประกอบเบา ๆ (ต้นแบบใช้ "Digital Clouds" – Mixkit ฟรี) ใส่เครดิตในแคปชั่น

## 2. โครงเรื่อง 10 ช่วง (สูตรหลัก)
| # | เวลา | ช่วง | กราฟที่ใช้ | ทำอะไร |
|---|---|---|---|---|
| 1 | 0–6s | **Hook ผลงานเมื่อวาน** | 4H มีเส้น ✓ เป้า | "แผนเมื่อวานถึงเป้าแล้ว" + ราคาตอนนี้ → สร้างความน่าเชื่อถือทันที |
| 2 | 6–8s | มุมมองวันนี้ 1 ประโยค | 4H | "ยังมองขาย แต่รอเด้งก่อน" |
| 3 | 8–18s | **ทวนแผนเมื่อวาน** | 1H มีโซน, High, SL ✗ไม่โดน, เป้า1 ✓, เป้า2 ✗ | เช็กลิสต์ ✓/✗ ตรงไปตรงมา |
| 4 | 18–30s | วิเคราะห์ **4H** | Double Top / Low / LH / แนวรับ | ใส่ป้ายบนกราฟทีละจุดตามเสียง |
| 5 | 30–38s | วิเคราะห์ **1H** | High / LH เส้นซิกแซก | "ไฮยังต่ำลง" |
| 6 | 38–46s | วิเคราะห์ **15M** | กล่องกรอบสีเหลือง | "อยู่กลางกรอบ ไม่ไล่ขาย รอเด้งก่อน" |
| 7 | 46–65s | **แผนหลัก** (Sell on Rally) | 4H โซนแดง + ลูกศรแดงจำลอง + เส้นเขียวประเป้า1/2 + SL | โซนรอขาย → เป้า1 → เป้า2 → SL → เงื่อนไขจบมุมมอง |
| 8 | 65–74s | **แผนสำรอง** | 4H ลูกศรน้ำเงินขึ้น + โซนฟ้า | เงื่อนไข "1H ปิดเหนือ X" → เป้าเด้ง |
| 9 | 74–86s | **ความน่าจะเป็น** | การ์ดแถบ แดง:น้ำเงิน (เช่น 55:45) + เหตุผล 3–4 ข้อ ✓ | ปิดท้าย "ไม่ใช่การันตี" |
| 10 | 86–100s | **CTA** | การ์ด "เลขสำคัญวันนี้" → การ์ดโหวต ▼ลงต่อ / ▲เด้งกลับ → โลโก้ | ขอเซฟ, ขอคอมเมนต์, ขอติดตาม |

**จุดเด่นที่ทำให้คลิปแนวนี้ได้ผล**
1. เปิดด้วย "แผนเมื่อวานถึงเป้าแล้ว ✅" = พิสูจน์ผลงานทุกวัน (ถ้าไม่ถึงก็บอกตรง ๆ ✗)
2. ตัวเลขชัด จำง่าย ซ้ำหลายรอบ (เสียง + ป้ายบนกราฟ + แถวข้อมูล)
3. มีแผน A/B + เงื่อนไขยกเลิก → ดูเป็นมืออาชีพ ไม่ฟันธง
4. ปิดด้วยการ์ดตัวเลขให้ **เซฟ** + คำถาม 2 ตัวเลือกให้ **คอมเมนต์** (ดันการมองเห็น)
5. ทำ **ทุกวัน** หัวข้อเดิม = ซีรีส์

## 4. สีและฟอนต์
| ใช้กับ | สี (ประมาณ) |
|---|---|
| พื้นหลัง | น้ำเงินกรมท่าเข้ม ไล่เฉด `#0B1220 → #111A2E` |
| ตัวเลข/คำเน้น/โลโก้ | ทอง `#F5B800` |
| ขาย / ลง / SL / แนวต้าน / โซนขาย | แดง `#F04452` (โซนใช้แดงอ่อนโปร่ง) |
| เป้า / ✓ ถึงแล้ว | เขียว `#22C55E` (เส้นประ) |
| แผนสำรอง / เด้ง | น้ำเงิน `#3B82F6` |
| กรอบไซด์เวย์ 15M | เหลืองอ่อน |
| แถวข้อมูล | กล่องมนสีเข้ม `#1A2236` ขอบบาง |

- ฟอนต์ต้นแบบ (ไทย) แนว Kanit/Prompt Bold
- **ภาษาลาวแนะนำ: Noto Sans Lao (Bold/Black)** หรือ Phetsarath OT — ห้ามใช้ฟอนต์ไทย เพราะจะไม่มีตัวอักษรลาว
- ป้ายบนกราฟ: แคปซูลสีทึบ ตัวขาว เช่น `High 3,923`, `LH 3,906`, `Low 3,853`, `DOUBLE TOP`, `SL 3,930 ✗ ບໍ່ໂດນ`, `✓ ເປົ້າ 1 · 3,870`

## 5. เสียงพากย์ภาษาลาว
- ความเร็ว ~3 คำ/วินาที, เว้นจังหวะสั้นมาก ทุกประโยคขึ้นซับตรงกัน
- AI Voice ที่รองรับลาว: **Azure TTS `lo-LA-ChanthavongNeural` (ชาย) / `lo-LA-KeomanyNeural` (หญิง)**
  หรืออัดเสียงเอง (ดีที่สุดสำหรับความเป็นธรรมชาติ)
- อ่านตัวเลขแบบ: 3,870 = "ສາມພັນແປດຮ້ອຍເຈັດສິບ" (หรืออ่านแบบเทรดเดอร์ "ສາມແປດເຈັດສິບ" ให้คงที่ทั้งคลิป)
- คำว่าทอง: ใช้ **ຄຳ** (คำลาวแท้) — ถ้ากลุ่มผู้ชมคุ้นกับ "ທອງ" ก็ใช้ได้ แต่ให้ใช้คำเดียวตลอดคลิป

## 6. ขั้นตอนทำคลิปทุกวัน (Workflow)
1. เปิด TradingView → OANDA:XAUUSD แคปกราฟ 4H, 1H, 15M (จดเวลาแคป)
2. ทวนแผนเมื่อวาน: โซน, High ที่ทำได้, โดน SL ไหม, เป้า 1/2 ถึงไหม
3. หาโครงสร้าง: Double Top/Bottom, HH/HL/LH/LL, แนวรับ/ต้าน, กรอบ 15M
4. เขียนแผน A (หลัก) + แผน B (สำรอง) + เงื่อนไขยกเลิก + ความน่าจะเป็น
5. เติมตัวเลขลง `template-lo.md` → ได้ทั้งเสียงพากย์, ข้อความบนจอ, แคปชั่น
6. ทำเสียงพากย์ → ตัดต่อ (CapCut ได้) ตามตารางช็อต → ใส่ป้ายบนกราฟตามเสียง
7. โพสต์เวลาเช้า (ต้นแบบแคปกราฟ 05:56 น.) + แคปชั่นจากแม่แบบ + แฮชแท็ก
