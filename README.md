# 📒 Gold Record Bot: ห้องรีคอร์ดผลเทรดทองคำบน Discord

## ห้องที่บอทสร้างให้ (คำสั่ง `/setup`) • ภาษาไทย + ภาษาลาว
```
📊 RECORD ROOM
 ├ #📒บันทึกเทรด・ບັນທຶກເທຣດ            ← ทุกคนอ่านได้ บอทโพสต์อย่างเดียว
 ├ #📈สถิติ・ສະຖິຕິ                     ← สรุปอัตโนมัติทุกวัน 23:30 น.
 ├ #📰ปฏิทินข่าว・ປະຕິທິນຂ່າວ            ← เตือนข่าวแรง + สรุปข่าวทุกเช้า 07:00 น.
 ├ #📝สมุดเทรดสมาชิก・ປຶ້ມບັນທຶກສະມາຊິກ   ← การ์ดเทรดของสมาชิกแต่ละคน
 ├ #🏆อันดับเทรดเดอร์・ອັນດັບເທຣດເດີ       ← ประกาศอันดับทุกวันอาทิตย์ 20:00 น.
 └ #💬คุยผลเทรด・ລົມຜົນເທຣດ             ← ทุกคนพิมพ์ได้
```
- ทุกห้องมีคำอธิบายห้อง (topic) และ **คู่มือปักหมุด** เป็นภาษาไทยและภาษาลาว
- ถ้าเซิร์ฟเวอร์เคยรัน `/setup` ไว้แล้ว (ชื่อห้องภาษาไทยอย่างเดียว) ให้รัน `/setup` อีกครั้ง
  บอทจะ **เปลี่ยนชื่อห้องเดิม** ข้อความเก่าอยู่ครบ ไม่สร้างห้องซ้ำ
- แก้ชื่อห้องหรือคำแปลได้ที่ไฟล์ `rooms.py` ไฟล์เดียว
  (ถ้าเปลี่ยน `name` ให้ใส่ชื่อเดิมไว้ใน `legacy` บอทจะได้หาห้องเดิมเจอ)

## วิธีติดตั้ง
1. ไปที่ https://discord.com/developers/applications แล้วกด **New Application** → แท็บ **Bot** → **Reset Token** แล้วคัดลอกโทเคนเก็บไว้
2. แท็บ **OAuth2 → URL Generator** เลือก `bot` + `applications.commands`
   แล้วเลือกสิทธิ์ **Manage Roles, Manage Channels, Send Messages, Embed Links, Read Message History**
   จากนั้นเปิดลิงก์ที่ได้เพื่อเชิญบอทเข้าเซิร์ฟเวอร์
3. รันบอท:
   ```bash
   pip install -r requirements.txt
   export DISCORD_TOKEN=xxxx
   export GUILD_ID=123456789   # คลิกขวาที่ชื่อเซิร์ฟเวอร์ → Copy Server ID
   python bot.py
   ```
4. ใน Discord พิมพ์ `/setup` แล้วให้ Role **Recorder** กับคนที่ทำหน้าที่บันทึกเทรด

ข้อมูลทั้งหมดเก็บในไฟล์ `records.db` ควรสำรองไฟล์นี้เป็นประจำ

## 🤖 บันทึกอัตโนมัติจาก TradingView

ไฟล์ `tradingview/gold_record_system.pine` เป็นระบบเทรดทองที่เขียนกฎไว้ครบแล้ว:
- ดูเทรนด์จาก EMA 50/200 บน H1
- เข้าเมื่อราคาย่อแตะ EMA20 บน M15 แล้วมีแท่งยืนยัน
- SL = 1.5 × ATR, TP = 1:2
- เทรดเฉพาะ 14:00–23:00 น. (เวลาไทย)

เมื่อเข้าออเดอร์ บอทจะโพสต์การ์ดในห้องบันทึกเทรดเอง เมื่อชน TP หรือ SL บอทจะปิดการ์ดและคำนวณ R ให้เอง

**วิธีตั้งค่า**
1. ใส่ `WEBHOOK_SECRET` ในไฟล์ `.env` ของบอท
2. TradingView → Pine Editor → วางโค้ด → Add to chart (กราฟ XAUUSD, M15)
3. ในตั้งค่าของสคริปต์ ใส่ Webhook secret ให้ตรงกับข้อ 1
4. สร้าง Alert: Condition = *Gold Record System*
   - Message: `{{strategy.order.alert_message}}`
   - Notifications → Webhook URL: `https://<โดเมนบอท>/webhook`

> ⚠️ Webhook ของ TradingView ต้องใช้แพ็กเกจที่เสียเงิน และส่งได้เฉพาะพอร์ต 80/443 เท่านั้น
> จึงต้องมีโดเมน HTTPS (เช่น Railway / Render ให้มาฟรี หรือใช้ Caddy บน VPS)

**ส่งเองจากระบบอื่นก็ได้** (เช่น EA บน MT5) ด้วย POST JSON:
```json
{"secret":"...","action":"open","side":"BUY","entry":2650.5,"sl":2640.2,"tp":2671.1,"ref":"A1"}
{"secret":"...","action":"close","ref":"A1","price":2671.1}
{"secret":"...","action":"cancel","ref":"A1"}
```

## 📰 เตือนข่าวแรง

ดึงปฏิทินจาก ForexFactory ชั่วโมงละครั้ง แล้วโพสต์ในห้อง #📰ปฏิทินข่าว:
- **07:00 น.** สรุปข่าวแรงของวันนั้น พร้อมค่าคาดการณ์และค่าครั้งก่อน
- **30 นาทีก่อนข่าว** ⚠️ เตือนให้งดเปิดออเดอร์ และบอกว่ามีออเดอร์ค้างอยู่กี่ไม้
- **ตอนข่าวออก** 🔴 เตือนให้รอราคานิ่งก่อนเข้าเทรด
- ข่าวที่ออกเวลาเดียวกัน (เช่น NFP และอัตราว่างงาน) จะรวมเป็นข้อความเดียว
- ออเดอร์ที่เปิดภายใน ±30 นาทีรอบเวลาข่าว จะติดป้าย "⚠️ เปิดในช่วงข่าวแรง" ในการ์ด
  ทั้งออเดอร์ที่พิมพ์เองและออเดอร์จาก TradingView

ปรับค่าได้ใน `.env`:
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `NEWS_CURRENCIES` | `USD` | สกุลเงินที่ติดตาม (หลายสกุลคั่นด้วย `,`) |
| `NEWS_IMPACT` | `High` | ระดับข่าว ใส่ `High,Medium` ถ้าต้องการข่าวกลางด้วย |
| `NEWS_LEAD` | `30` | เตือนก่อนข่าวกี่นาที |
| `NEWS_BLACKOUT` | `30` | ช่วงห้ามเทรด ± กี่นาที |

> ถ้าเคยรัน `/setup` ไปแล้ว ให้รันอีกครั้ง บอทจะสร้างเฉพาะห้อง #📰ปฏิทินข่าว ที่ยังไม่มี
> สมาชิกที่อยากได้แจ้งเตือนในมือถือ ให้คลิกขวาที่ห้อง → Notification Settings → All Messages

## 📝 สมุดเทรดสมาชิก + 🏆 อันดับ

สมาชิกทุกคนบันทึกเทรดของตัวเองได้ด้วย `/journal open` แล้วการ์ด (เลข `J0001`) จะขึ้นในห้อง #📝สมุดเทรดสมาชิก
- เก็บ **แยกจากออเดอร์ทางการ** (`#0001`) สถิติของห้องจึงไม่ปนกับของสมาชิก
- ปิดหรือยกเลิกได้เฉพาะเทรดของตัวเอง แอดมินยกเลิกของคนอื่นได้ (ใช้จัดการคนที่บันทึกมั่ว) แต่ปิดแทนไม่ได้
- ติดป้าย "⚠️ เปิดในช่วงข่าวแรง" เหมือนออเดอร์ทางการ
- อันดับเรียงตาม **R รวม** ถ้าเท่ากันดู Profit factor แล้วดู Win rate
- ต้องปิดเทรดอย่างน้อย `LEADERBOARD_MIN_TRADES` ไม้ (ค่าเริ่มต้น 5) จึงจะติดอันดับ กันคนที่ฟลุคได้ไม้เดียว
- รายชื่อในอันดับแสดงเป็น mention แต่ไม่แจ้งเตือนใคร

> ⚠️ ข้อมูลในสมุดเทรดเป็นสิ่งที่สมาชิก **บันทึกเอง** บอทตรวจสอบกับบัญชีเทรดจริงไม่ได้
> สิ่งที่ช่วยให้น่าเชื่อถือคือ การ์ดทุกใบมีเวลาบันทึกและแก้ย้อนหลังไม่ได้ ใครบันทึกตอนปิดแล้วจะเห็นได้ชัด
> ถ้าจะแจกรางวัลตามอันดับ ควรขอดูหลักฐานจากบัญชีจริง (เช่น Myfxbook) ประกอบด้วย

## 📈 กราฟ R สะสม

`/stats`, `/journal stats` และสรุปประจำวัน (23:30 น.) จะแนบกราฟ R สะสมมาด้วย (ต้องปิดอย่างน้อย 2 ไม้)
- เส้นสีฟ้า = R สะสมเรียงตามลำดับเทรด และปลายเส้นแสดงค่าล่าสุด
- พื้นที่สีแดง = ช่วง Drawdown (ระยะห่างจากจุดสูงสุดเดิม)
- กราฟใช้ฟอนต์ไทยในเครื่อง ไฟล์ Docker ติดตั้ง `fonts-thai-tlwg` ให้แล้ว
  ถ้ารันเองบน Linux ให้ติดตั้ง: `sudo apt install fonts-thai-tlwg`
  ถ้าเครื่องไม่มีฟอนต์ไทย กราฟจะใช้ป้ายภาษาอังกฤษแทน ตัวอักษรจะไม่กลายเป็นกล่องสี่เหลี่ยม

## 🇹🇭🇱🇦 ภาษาไทย + ภาษาลาว

Discord ไม่มีภาษาลาวในตัวเลือกภาษาของแอป บอทจึงจัดการภาษาเอง:

| ข้อความ | ใช้ภาษาอะไร |
|---|---|
| ข้อความที่ตอบคนพิมพ์คำสั่ง (`/stats`, `/news`, `/journal ...` ฯลฯ) | ภาษาที่คนนั้นเลือกด้วย `/language` (ถ้ายังไม่เลือก ใช้ `DEFAULT_LANG`) |
| ข้อความที่บอทโพสต์ให้ทุกคน (การ์ดออเดอร์ เตือนข่าว สรุปรายวัน อันดับ) | `PUBLIC_LANG` |
| ชื่อห้อง คำอธิบายห้อง คู่มือปักหมุด คำอธิบายคำสั่ง | ไทย + ลาว เสมอ |
| กราฟ | ภาษาเดียวกับข้อความที่แนบกราฟไป |

ค่าใน `.env`: `th` = ไทย, `lo` = ລາວ, `both` = สองภาษา (ค่าเริ่มต้นของทั้งสองตัวคือ `both`)

- ข้อความแปลทั้งหมดอยู่ใน `i18n.py` ส่วนชื่อข่าวภาษาไทย/ลาวอยู่ใน `news.py` (`LOCAL_NAMES`)
- ไฟล์ Docker ติดตั้งฟอนต์ไทย (`fonts-thai-tlwg`) และฟอนต์ลาว (`fonts-lao`) ให้แล้ว
  ถ้ารันเองบน Linux: `sudo apt install fonts-thai-tlwg fonts-lao`
- เวลาในข้อความเป็น UTC+7 ซึ่งตรงกันทั้งไทยและลาว
