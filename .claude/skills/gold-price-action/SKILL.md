ເນື້ອຫາສະຫຼຸບຈາກຄຳອະທິບາຍ (caption) ຂອງ 20 ຄລິບລ່າສຸດ (ພ.ຈ. 2026) ຄລິບທີ່ມີແຕ່ສຽງເວົ້າ ແລະບໍ່ມີຄຳອະທິບາຍ ຍັງບໍ່ໄດ້ຖອດຄວາມ

ແນວຄິດຫຼັກ: **ອ່ານກຣາຟໃຫ້ຄືອ່ານແຮງຂອງຄົນ ບໍ່ແມ່ນພຽງແຕ່ເບິ່ງວ່າລາຄາຂຶ້ນ ຫຼືລົງ**

## 1. ອົງປະກອບຂອງແທ່ງທຽນ 1 ແທ່ງ
- ມີ 4 ຄ່າ: ລາຄາເປີດ (O), ລາຄາປິດ (C), ຈຸດສູງສຸດ (H), ຈຸດຕ່ຳສຸດ (L)
- ປິດສູງກວ່າເປີດ = ແທ່ງຂຽວ ຝັ່ງ BUY ຊະນະ · ປິດຕ່ຳກວ່າເປີດ = ແທ່ງແດງ ຝັ່ງ SELL ຊະນະ
- ໄສ້ທຽນ = ລາຄາເຄີຍໄປຮອດ ແຕ່ຢືນຢູ່ບໍ່ໄດ້
  - ໄສ້ເທິງຍາວ = ຂຶ້ນໄປສູງ ແຕ່ຖືກແຮງຂາຍກົດລົງມາ
  - ໄສ້ລຸ່ມຍາວ = ລົງໄປເລິກ ແຕ່ມີແຮງຊື້ດັນກັບຄືນ
- ໂຕທຽນນ້ອຍຈົນເກືອບເປັນເສັ້ນ = ສອງຝັ່ງຍັງສູ້ກັນຢູ່ ຕະຫຼາດລັງເລ

## 2. ເບິ່ງຂະໜາດແທ່ງ ກໍຮູ້ວ່າຝັ່ງໃດຊະນະ (ຄລິບຫຼັກ)
| ລັກສະນະແທ່ງ | ຄວາມໝາຍ |
|---|---|
| ໂຕຍາວ ໄສ້ສັ້ນ | ຝັ່ງໜຶ່ງຄຸມເກມທັງແທ່ງ |
| ຂຽວໂຕຍາວ | BUY ໄລ່ລາຄາຂຶ້ນຕັ້ງແຕ່ເປີດຈົນປິດ |
| ແດງໂຕຍາວ | SELL ກົດລາຄາລົງບໍ່ຢຸດ |
| ໂຕນ້ອຍ ໄສ້ຍາວທັງສອງຂ້າງ | ແຮງເລີ່ມໝົດ ຍັງບໍ່ມີໃຜຊະນະຂາດ |

**ເບິ່ງຫຼາຍແທ່ງຕໍ່ກັນ ສຳຄັນກວ່າເບິ່ງແທ່ງດຽວ**
- ແທ່ງຂຽວສັ້ນລົງເລື້ອຍໆ = ແຮງຊື້ອ່ອນລົງ ຂາຂຶ້ນເລີ່ມເມື່ອຍ
- ຖ້າຕາມດ້ວຍແທ່ງແດງໂຕຍາວ = ຝັ່ງຂາຍເລີ່ມຍຶດເກມ (ແລະກົງກັນຂ້າມໃນຂາລົງ)

## 3. ແທ່ງກັບໂຕ 3 ແບບ
- 🔨 **ຄ້ອນ (Hammer)**: ໄສ້ລຸ່ມຍາວ ຖືກທຸບລົງໄປ ແຕ່ຝັ່ງຊື້ດັນກັບຄືນ ຖ້າເກີດຫຼັງລາຄາລົງມາດົນ = ຝັ່ງຂາຍເລີ່ມໝົດແຮງ
- 🌠 **ດາວຕົກ (Shooting Star)**: ໄສ້ເທິງຍາວ ພຸ່ງຂຶ້ນໄປ ແຕ່ຖືກຕົບກັບລົງມາ ຖ້າເກີດຫຼັງລາຄາຂຶ້ນແຮງ = ຝັ່ງຊື້ເລີ່ມໝົດແຮງ
- 🟩 **ກືນກິນ (Engulfing)**: ແທ່ງໃໝ່ໂຕໃຫຍ່ ກືນແທ່ງກ່ອນໜ້າທັງແທ່ງ ຂຽວກືນແດງ = ຝັ່ງຊື້ຍຶດເກມ · ແດງກືນຂຽວ = ຝັ່ງຂາຍຍຶດເກມ
- ⚠️ **ຕ້ອງເກີດຢູ່ແນວຮັບ ຫຼືແນວຕ້ານເທົ່ານັ້ນ** ຖ້າເກີດກາງທາງ ສ່ວນຫຼາຍເປັນສັນຍານຫຼອກ

## 4. ຊອກແນວຮັບແນວຕ້ານຈາກໄສ້ທຽນ
- ໄສ້ລຸ່ມຍາວໄປຈົບທີ່ລະດັບເດີມຫຼາຍຄັ້ງ = **ແນວຮັບ** (ມີຄົນລໍຖ້າຊື້ຢູ່ບ່ອນນັ້ນ)
- ໄສ້ເທິງຍາວໄປຈົບທີ່ລະດັບເດີມຫຼາຍຄັ້ງ = **ແນວຕ້ານ** (ມີຄົນລໍຖ້າຂາຍ)
- ຍິ່ງລາຄາຖືກປະຕິເສດຢູ່ລະດັບນັ້ນຫຼາຍຄັ້ງ ແນວຍິ່ງແຂງ
- ຖ້າແທ່ງໂຕຍາວ**ປິດ**ທະລຸແນວໄດ້ = ແນວແຕກແລ້ວ
- ແນວຮັບທີ່ແຕກ ມັກກາຍເປັນແນວຕ້ານໃໝ່ (ແລະແນວຕ້ານທີ່ແຕກ ມັກກາຍເປັນແນວຮັບ) ເພາະລາຄາຈື່ໄດ້ວ່າເຄີຍເຈັບຢູ່ບ່ອນໃດ

## 5. ວັນຂ່າວແຮງ (ຄຳ / USD)
- ຕັ້ງແຕ່ສະຫະລັດເຂົ້າເວລາລະດູໜາວ (ພ.ຈ.–ມີ.ນ.) ຂ່າວຫຼັກຈະອອກ **20:30 ໂມງ ເວລາລາວ/ໄທ** (ຊ່ວງລະດູຮ້ອນອອກ 19:30 ໂມງ)
- ຂ່າວທີ່ຕ້ອງຕິດຕາມ: NFP / ອັດຕາຫວ່າງງານ, CPI / Core CPI, PPI, ຂໍຮັບສະຫວັດດີການຫວ່າງງານ, ຍອດຂາຍຍ່ອຍ, GDP + Core PCE, FOMC ແລະ Minutes, ກຳມະການເຟດຂຶ້ນເວົ້າ
- ວິທີອ່ານຜົນຂ່າວ:
  - ຕົວເລກ "ຮ້ອນກວ່າຄາດ" (ເງິນເຟີ້ສູງ ຫຼືການຈ້າງງານແຂງ) → ເຟດມີເຫດຜົນຂຶ້ນດອກເບ້ຍ ໂດລາແຂງ **ຄຳມັກຖືກກົດ**
  - ຕົວເລກ "ເຢັນກວ່າຄາດ" (ເງິນເຟີ້ຕ່ຳ ຫຼືການຈ້າງງານອ່ອນ) → ໂດລາອ່ອນ **ຄຳມີແຮງໜູນ**
  - ຂໍຮັບສະຫວັດດີການຫວ່າງງານຕ່ຳກວ່າຄາດ = ຕະຫຼາດແຮງງານແຂງ → ຄຳມີສິດຖືກກົດ
- **ກົດວັນຂ່າວ (ຢ້ຳໃນທຸກຄລິບ)**:
  1. ຫຼຸດຂະໜາດໄມ້
  2. ບໍ່ດັກອໍເດີກ່ອນຕົວເລກອອກ ແລະບໍ່ເດົາຕົວເລກ
  3. ບໍ່ໄລ່ແທ່ງທຳອິດຫຼັງຂ່າວອອກ
  4. ລໍຖ້າໃຫ້ຕະຫຼາດເລືອກທາງກ່ອນ ແລ້ວຈຶ່ງຕາມ
- ລະບຸ**ລະດັບລາຄາຈິດຕະວິທະຍາ**ໄວ້ສະເໝີ ເຊັ່ນ 4,000 / 4,100 ວ່າຖ້າຫຼຸດຈະເປັນແນວໃດ ແລະຖ້າຢືນໄດ້ຈະເປັນແນວໃດ

## 6. ຈິດຕະວິທະຍາການໃຊ້ລະບົບ
- ລະບົບທີ່ຊະນະ 60% ຍັງມີໂອກາດເສຍ 40% ສະເໝີ ຖ້າເທຣດ 100 ໄມ້ ໂອກາດເຈີເສຍຕິດກັນ 4 ໄມ້ຢ່າງໜ້ອຍ 1 ຄັ້ງແມ່ນສູງຫຼາຍ
- ກ່ອນຈະປ່ຽນລະບົບ ໃຫ້ຖາມຕົວເອງ 3 ຂໍ້:
  1. ເຮັດຕາມກົດຂອງລະບົບຄົບທຸກໄມ້ ຫຼືບໍ່
  2. ຂາດທຶນຄັ້ງນີ້ຍັງຢູ່ໃນຂອບທີ່ລະບົບເຄີຍເຈີມາບໍ່ (ເຊັ່ນ max drawdown ແລະຈຳນວນຄັ້ງທີ່ເສຍຕິດກັນ)
  3. ໃນໄລຍະຍາວ ລະບົບຍັງເຮັດກຳໄລໄດ້ຕາມທີ່ຄວນບໍ່
- ຖ້າຍັງເຮັດຕາມແຜນ = ເລື່ອງປົກກະຕິຂອງການເທຣດ · ຖ້າຜົນເລີ່ມປ່ຽນ = ຮອດເວລາກວດລະບົບແທ້ຈັງ
- ຢ່າຖິ້ມລະບົບພຽງເພາະເສຍຕິດກັນ ແຕ່ກໍຢ່າໃຊ້ຄຳວ່າ "ສະຖິຕິ" ເປັນຂໍ້ອ້າງ
- 90% ຂອງເທຣດເດີຂາດທຶນ ເພາະລໍຖ້າບໍ່ເປັນ: ລໍຖ້າໃຫ້ແທ່ງຢືນຢັນຢູ່ແນວກ່ອນ ຢ່າຟ້າວເຂົ້າ

## 7. ຮູບແບບເນື້ອຫາຂອງເພຈ (ໃຊ້ຂຽນໂພສ ຫຼືຂໍ້ຄວາມໃນຫ້ອງ Discord)
1. ເປີດດ້ວຍອີໂມຈິ + ຄຳຖາມ ເຊັ່ນ "ຮູ້ບໍ່? ..." ຫຼື "🚨 x ດ່ານຂ່າວແຮງ! ຄືນນີ້ ..."
2. ເນື້ອຫາເປັນແຖວສັ້ນ 1 ອີໂມຈິຕໍ່ 1 ແນວຄິດ ໃຊ້ຮູບແບບ "ສິ່ງທີ່ເຫັນ = ຄວາມໝາຍ"
3. ສຳລັບຂ່າວ: ຄຳເໜັງຕີງຈັກ $ ໃນຊ່ວງທີ່ຜ່ານມາ → ລາຍການຂ່າວພ້ອມເວລາ ຄ່າຄາດການ ແລະຄ່າຄັ້ງກ່ອນ → "ຄຳຈະໄປທາງໃດ?" 🔻/🔺 → ແນວລາຄາສຳຄັນ → ກົດວັນຂ່າວ

## ວິທີໃຊ້ສະກິວນີ້ກັບໂປຣເຈັກ Gold-trade
- **ພາສາ**: ຂໍ້ຄວາມທີ່ສົ່ງໃຫ້ສະມາຊິກ ຫຼືໂພສໃນຫ້ອງ Discord ໃຫ້ຂຽນເປັນພາສາລາວ ແລະໃຊ້ຄຳສັບດຽວກັບ `i18n.py` (ເຊັ່ນ ເທຣດ, ກຳໄລ, ຂາດທຶນ, ຂ່າວແຮງ, ເທຣດເດີ)
- **Pine Script** (`tradingview/gold_record_system.pine`): ລະບົບເດີມເຂົ້າເມື່ອລາຄາຍໍ່ແຕະ EMA20 ເທິງ M15 ແລ້ວມີ "ແທ່ງຢືນຢັນ" ໃຊ້ຂໍ້ 2–3 ກຳນົດແທ່ງຢືນຢັນໃຫ້ຈະແຈ້ງໄດ້ ເຊັ່ນ
  - ຄ້ອນ: `lowerWick >= 2*body` ແລະ `upperWick <= body`
  - ດາວຕົກ: ກົງກັນຂ້າມກັບຄ້ອນ
  - ກືນກິນ: `close > open[1] and open < close[1]` (ຝັ່ງຂາຂຶ້ນ)
  - ແທ່ງແຮງ: `body >= 0.6*(high-low)`
  - ໝົດແຮງ: ໂຕແທ່ງນ້ອຍລົງຕໍ່ກັນ 3 ແທ່ງ
  - ກົດເຫຼົ່ານີ້ໃຊ້ສະເພາະເມື່ອລາຄາຢູ່ໃກ້ແນວ (ເຊັ່ນ EMA20 ຫຼື swing high/low ພາຍໃນໄລຍະ 0.5×ATR)
- **ບອທຂ່າວ** (`news.py`, ຫ້ອງ #ປະຕິທິນຂ່າວ): ໃສ່ກົດວັນຂ່າວໃນຂໍ້ 5 ລົງໃນຂໍ້ຄວາມເຕືອນ ແລະໃຊ້ຊ່ວງ `blackout` ງົດເປີດອໍເດີກ່ອນ ແລະຫຼັງຂ່າວແຮງ
- **ຫ້ອງສະຖິຕິ ແລະປຶ້ມບັນທຶກເທຣດ**: ໃຊ້ຂໍ້ 6 ເປັນຂໍ້ຄວາມເຕືອນເມື່ອເສຍຕິດກັນ N ໄມ້ ແລະທຽບກັບ max losing streak ຂອງລະບົບ
- ຫ້າມກ໊ອບປີ້ຄຳອະທິບາຍຂອງເພຈໄປໂພສຊ້ຳທັງກ້ອນ ໃຫ້ຂຽນໃໝ່ດ້ວຍຄຳຂອງເຮົາເອງ
