# สกิล: อ่านแรงซื้อขายจากแท่งเทียน + เทรดทองในวันข่าว

ที่มา: Reels ของเพจ Boss - Life of a Trader (facebook.com/bosslifeofatrader)
คลิปหลัก: facebook.com/reel/1954888995488761
เนื้อหาสรุปจากแคปชันของ 20 คลิปล่าสุด (พ.ย. 2026) คลิปที่มีแต่เสียงพูดและไม่มีแคปชันยังไม่ได้ถอดความ

แนวคิดหลัก: **อ่านกราฟให้เหมือนอ่านแรงของคน ไม่ใช่แค่ดูว่าราคาขึ้นหรือลง**
แท่งเทียนไม่ได้บอกอนาคต แต่บอกว่าฝั่งไหนกำลังชนะ และฝั่งไหนเริ่มหมดแรง

---

## 1. องค์ประกอบของแท่งเทียน 1 แท่ง
- มี 4 ค่า: ราคาเปิด (O), ราคาปิด (C), จุดสูงสุด (H), จุดต่ำสุด (L)
- ปิดสูงกว่าเปิด = แท่งเขียว ฝั่ง BUY ชนะ · ปิดต่ำกว่าเปิด = แท่งแดง ฝั่ง SELL ชนะ
- ไส้เทียน = ราคาเคยไปถึง แต่ยืนอยู่ไม่ได้
  - ไส้บนยาว = ขึ้นไปสูง แต่โดนแรงขายกดลงมา
  - ไส้ล่างยาว = ลงไปลึก แต่มีแรงซื้อดันกลับ
- ตัวเทียนเล็กจนเกือบเป็นเส้น = สองฝั่งยังสู้กันอยู่ ตลาดลังเล

## 2. ดูขนาดแท่ง ก็รู้ว่าฝั่งไหนชนะ (คลิปหลัก)
| ลักษณะแท่ง | ความหมาย |
|---|---|
| ตัวยาว ไส้สั้น | ฝั่งหนึ่งคุมเกมทั้งแท่ง |
| เขียวตัวยาว | BUY ไล่ราคาขึ้นตั้งแต่เปิดจนปิด |
| แดงตัวยาว | SELL กดราคาลงไม่หยุด |
| ตัวเล็ก ไส้ยาวทั้งสองข้าง | แรงเริ่มหมด ยังไม่มีใครชนะขาด |

**ดูหลายแท่งต่อกันสำคัญกว่าดูแท่งเดียว**
- แท่งเขียวสั้นลงเรื่อยๆ = แรงซื้ออ่อนลง ขาขึ้นเริ่มเหนื่อย
- ถ้าตามด้วยแท่งแดงตัวยาว = ฝั่งขายเริ่มยึดเกม (และกลับด้านกันในขาลง)

## 3. แท่งกลับตัว 3 แบบ
- 🔨 **ค้อน (Hammer)**: ไส้ล่างยาว โดนทุบลงไปแต่ฝั่งซื้อดันกลับ ถ้าเกิดหลังราคาลงมานาน = ฝั่งขายเริ่มหมดแรง
- 🌠 **ดาวตก (Shooting Star)**: ไส้บนยาว พุ่งขึ้นไปแต่โดนตบกลับลงมา ถ้าเกิดหลังราคาขึ้นแรง = ฝั่งซื้อเริ่มหมดแรง
- 🟩 **กลืนกิน (Engulfing)**: แท่งใหม่ตัวใหญ่กลืนแท่งก่อนหน้าทั้งแท่ง เขียวกลืนแดง = ฝั่งซื้อยึดเกม · แดงกลืนเขียว = ฝั่งขายยึดเกม
- ⚠️ **ต้องเกิดตรงแนวรับหรือแนวต้านเท่านั้น** ถ้าเกิดกลางทาง ส่วนใหญ่เป็นสัญญาณหลอก

## 4. หาแนวรับแนวต้านจากไส้เทียน
- ไส้ล่างยาวไปจบที่ระดับเดิมหลายครั้ง = **แนวรับ** (มีคนรอซื้ออยู่ตรงนั้น)
- ไส้บนยาวไปจบที่ระดับเดิมหลายครั้ง = **แนวต้าน** (มีคนรอขาย)
- ยิ่งราคาโดนปฏิเสธที่ระดับนั้นหลายครั้ง แนวยิ่งแข็ง
- ถ้าแท่งตัวยาว**ปิด**ทะลุแนวได้ = แนวแตกแล้ว
- แนวรับที่แตกมักกลายเป็นแนวต้านใหม่ (และแนวต้านที่แตกมักกลายเป็นแนวรับ) เพราะราคาจำได้ว่าเคยเจ็บตรงไหน

## 5. วันข่าวแรง (ทองคำ / USD)
- ตั้งแต่สหรัฐฯ เข้าเวลาฤดูหนาว (พ.ย.–มี.ค.) ข่าวหลักจะออก **20:30 น. เวลาไทย** (ช่วงฤดูร้อนออก 19:30 น.)
- ข่าวที่ต้องจับตา: NFP / อัตราว่างงาน, CPI / Core CPI, PPI, ขอรับสวัสดิการว่างงาน, ยอดค้าปลีก, GDP + Core PCE, FOMC และ Minutes, กรรมการเฟดขึ้นพูด
- วิธีอ่านผลข่าว:
  - ตัวเลข "ร้อนกว่าคาด" (เงินเฟ้อสูง หรือการจ้างงานแข็ง) → เฟดมีเหตุผลขึ้นดอกเบี้ย ดอลลาร์แข็ง **ทองมักโดนกด**
  - ตัวเลข "เย็นกว่าคาด" (เงินเฟ้อต่ำ หรือการจ้างงานอ่อน) → ดอลลาร์อ่อน **ทองมีแรงหนุน**
  - ขอรับสวัสดิการว่างงานต่ำกว่าคาด = ตลาดแรงงานแข็ง → ทองมีสิทธิ์โดนกด
- **กฎวันข่าว (ย้ำในทุกคลิป)**:
  1. ลดขนาดไม้
  2. ไม่ดักออเดอร์ก่อนตัวเลขออก และไม่เดาตัวเลข
  3. ไม่ไล่แท่งแรกหลังข่าวออก
  4. รอให้ตลาดเลือกทางก่อน แล้วค่อยตาม
- ระบุ**ระดับราคาจิตวิทยา**ไว้เสมอ เช่น 4,000 / 4,100 ว่าถ้าหลุดจะเป็นอย่างไร และถ้ายืนได้จะเป็นอย่างไร

## 6. จิตวิทยาการใช้ระบบ
- ระบบที่ชนะ 60% ยังมีโอกาสแพ้ 40% เสมอ ถ้าเทรด 100 ไม้ โอกาสเจอแพ้ติดกัน 4 ไม้อย่างน้อย 1 ครั้งสูงมาก
- ก่อนจะเปลี่ยนระบบ ให้ถามตัวเอง 3 ข้อ:
  1. ทำตามกฎของระบบครบทุกไม้หรือเปล่า
  2. ขาดทุนครั้งนี้ยังอยู่ในกรอบที่ระบบเคยเจอมาไหม (เช่น max drawdown และจำนวนครั้งที่แพ้ติดกัน)
  3. ในระยะยาว ระบบยังทำกำไรได้ตามที่ควรไหม
- ถ้ายังทำตามแผน = เรื่องปกติของการเทรด · ถ้าผลลัพธ์เริ่มเปลี่ยน = ถึงเวลาตรวจระบบจริงจัง
- อย่าทิ้งระบบเพียงเพราะแพ้ติดกัน แต่ก็อย่าใช้คำว่า "สถิติ" เป็นข้ออ้าง
- 90% ของเทรดเดอร์ขาดทุนเพราะรอไม่เป็น: รอให้แท่งยืนยันตรงแนว อย่ารีบเข้า

## 7. รูปแบบคอนเทนต์ของเพจ (ใช้เขียนโพสต์หรือข้อความในห้อง Discord)
1. Hook ขึ้นต้นด้วยอีโมจิ + คำถาม เช่น "รู้ไหม? ..." หรือ "🚨 x ด่านข่าวแรง! คืนนี้ ..."
2. เนื้อหาเป็นบรรทัดสั้น 1 อีโมจิต่อ 1 ไอเดีย ใช้รูปแบบ "สิ่งที่เห็น = ความหมาย"
3. สำหรับข่าว: ทองเคลื่อนไหวกี่ $ ในช่วงที่ผ่านมา → ลิสต์ข่าวพร้อมเวลา ค่าคาดการณ์ และค่าครั้งก่อน → "ทองไปทางไหน?" 🔻/🔺 → แนวราคาสำคัญ → กฎวันข่าว
4. ปิดท้ายด้วยประโยค 💡 สรุป 1 บรรทัด + CTA (เช่น ให้พิมพ์คำสั้นๆ ใต้คลิปเพื่อรับลิงก์กลุ่ม หรือชวนกดติดตาม) + แฮชแท็ก #เทรดทอง #ทองคำ #xauusd

## วิธีใช้สกิลนี้กับโปรเจกต์ Gold-trade
- **Pine Script** (`tradingview/gold_record_system.pine`): ระบบเดิมเข้าเมื่อราคาย่อแตะ EMA20 บน M15 แล้วมี "แท่งยืนยัน" ใช้ข้อ 2–3 นิยามแท่งยืนยันให้ชัดได้ เช่น
  - ค้อน: `lowerWick >= 2*body` และ `upperWick <= body`
  - ดาวตก: กลับด้านจากค้อน
  - กลืนกิน: `close > open[1] and open < close[1]` (ฝั่งขาขึ้น)
  - แท่งแรง: `body >= 0.6*(high-low)`
  - หมดแรง: ตัวแท่งเล็กลงต่อกัน 3 แท่ง
  - กฎเหล่านี้ใช้เฉพาะเมื่อราคาอยู่ใกล้แนว (เช่น EMA20 หรือ swing high/low ภายในระยะ 0.5×ATR)
- **บอทข่าว** (`news.py`, ห้อง #ปฏิทินข่าว): ใส่กฎวันข่าวในข้อ 5 ลงในข้อความเตือน และใช้ช่วง `blackout` งดเปิดออเดอร์ก่อนและหลังข่าวแรง
- **ห้องสถิติและสมุดเทรด**: ใช้ข้อ 6 เป็นข้อความเตือนเมื่อมีการแพ้ติดกัน N ไม้ และเทียบกับ max losing streak ของระบบ
- ห้ามคัดลอกแคปชันของเพจไปโพสต์ซ้ำทั้งก้อน ให้เขียนใหม่ด้วยคำของเราเอง
