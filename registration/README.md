# 📝 เว็บลงทะเบียนเรียนเทรด Forex & ทองคำ

ฟอร์มลงทะเบียนเรียนเทรด (ภาษาไทย) พร้อมหน้าแอดมินดูรายชื่อ
ใช้ Python ล้วน ๆ **ไม่ต้องติดตั้งไลบรารีเพิ่ม** ข้อมูลเก็บใน SQLite

## มีอะไรบ้าง
| หน้า | ทำอะไร |
|---|---|
| `/` | ฟอร์มลงทะเบียน: ข้อมูลส่วนตัว → ช่องทางติดต่อ → เลือกคลาส/วันเรียน → แบบสอบถาม → ยินยอม PDPA |
| `/?src=facebook` | ลิงก์ติดตามแหล่งที่มา ใช้ `src=` หรือ `utm_source=` เพื่อดูว่าโฆษณาช่องทางไหนได้คนมากที่สุด |
| `/admin` | ดูรายชื่อ ค้นหา เปลี่ยนสถานะ (ใหม่ / ติดต่อแล้ว / ชำระแล้ว / ยกเลิก) สถิติผู้เข้าชม และดาวน์โหลด CSV (เปิดใน Excel แล้วภาษาไทยไม่เพี้ยน) |

- หลังลงทะเบียน จะขึ้นหน้าต่าง "ลงทะเบียนสำเร็จ" พร้อมปุ่มเข้ากลุ่ม LINE หรือ WhatsApp หรือ Messenger
- ถ้าตั้ง `REG_DISCORD_WEBHOOK` บอทจะแจ้งเตือนในห้อง Discord ทุกครั้งที่มีคนลงทะเบียน
- กันสแปม: ส่งได้ไม่เกิน 5 ครั้งต่อ 10 นาทีต่อ IP มีช่องดักบอท (honeypot) และกันการลงทะเบียนซ้ำด้วยเบอร์เดิมในคลาสและวันเดียวกัน

## แก้เนื้อหา: แก้ไฟล์ `config.json` ไฟล์เดียว (ไม่ต้องรีสตาร์ท)
- `brand`: ชื่อแบรนด์ / สโลแกน / ลิงก์เว็บหลัก
- `hero`: ข้อความหัวเว็บ
- `course`: การ์ดรายละเอียดคอร์ส (เลเวล หัวข้อ วันที่ สถานที่)
- `classes`: คลาสที่ให้เลือก และวันเรียนของแต่ละคลาส (`dates: []` = ไม่ต้องเลือกวัน), `visible: false` = ซ่อนส่วนนี้
- `questions`: คำถามแบบสอบถาม (`multi: true` = เลือกได้หลายข้อ, `required: true` = บังคับตอบ)
- `contact` และ `success`: ลิงก์ LINE / WhatsApp / Messenger และกลุ่มนักเรียนที่แสดงหลังลงทะเบียนสำเร็จ

## วิธีรัน
```bash
REG_ADMIN_TOKEN=รหัสลับ python registration/server.py
# เปิด http://localhost:8090  และหน้าแอดมิน http://localhost:8090/admin
```
หรือใช้ Docker พร้อมบอท: `docker compose up -d --build` (ตั้งค่า `REG_ADMIN_TOKEN` ไว้ใน `.env`)
ข้อมูลจะอยู่ที่ `data/registrations.db`

ถ้าจะให้คนทั่วไปเข้าได้ ให้วางไว้หลังโดเมนที่มี HTTPS เช่น Cloudflare Tunnel, Nginx หรือ Caddy
แล้วแชร์ลิงก์เป็น `https://โดเมนของคุณ/?src=facebook`
